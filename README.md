# AIPet 桌面宠物

一款基于 **Tauri**、**Vite** 和 **TypeScript** 构建的 Windows 平台超高级、互动型桌面宠物应用。内置默认主宠为超萌且完全透明背景的英短银渐层小猫咪 **“喵喵 (Miaomiao)”**。

---

## ✨ 核心特色功能

- **内置原生“喵喵”主宠**：直接将超可爱的透明背景英短猫咪（Miaomiao）裁剪并封装为系统唯一的默认内置宠物，完美贴合桌面。
- **高阶毛玻璃 UI 界面**：聊天对话面板采用极具现代感的磨砂毛玻璃特效（`backdrop-filter: blur(12px)`），辅以顺滑的展开微动画与高透明度浮动气泡，视觉效果极佳。
- **极简隐形滚轴**：气泡聊天列表的滚动滑块被优化为平时近乎完全隐形的微透槽，极大减少对桌面的视觉遮挡，只在鼠标悬停时微微显现。
- **鼠标滚轮动态缩放（0.5x ~ 2.0x）**：直接把鼠标悬停在宠物身上并**滚动鼠标中键滚轮**即可自由放大或缩小宠物。系统会自动记忆并保存您喜好的缩放比例，再次启动时自动应用！
- **安静陪伴模式（静态闲置）**：宠物在闲置（`idle`）状态下会保持完全静止，避免频繁晃动打扰您的工作；只在被鼠标点击（触发趣味互动姿势）或处于聊天交互（思考与回复）时才会活泼地播放动画。
- **轻量 Fluent 卡片设置中心**：设置窗口重构为极具美感的 Win11 卡片式扁平化布局，包含胶囊式分段切换、发光聚焦边框、按压微动反馈以及薄型滚动槽。
- **DeepSeek AI 对话集成**：支持通过快捷菜单轻松配置 DeepSeek API Key 及自定义宠物角色扮演设定（System Prompt），让您的桌面宠物能聊、会撩、有温度。

## 🚀 环境准备与快速启动

为了在您的新电脑上顺利运行、开发或打包本项目，请确保您的系统已满足 [REQUIREMENTS.md](file:///c:/Users/Administrator/Project/pet/REQUIREMENTS.md) 中列出的开发工具链（包括 Node.js、Rust 编译器与 NSIS 打包器等）。

### 1. 安装项目依赖
在项目根目录下，安装所有前端依赖包：
```bash
npm install
```

### 2. 启动开发模式
同时启动 Vite 本地热重载开发服务器与 Tauri 桌面窗口环境：
```bash
npm run dev
# 并运行 Tauri 主体：
npx tauri dev
```

### 3. 生成可执行程序与安装包
一键编译 TS/CSS 代码并编译打包生成 Windows 直接运行的 `.exe` 绿色程序和安装器包：
```bash
npm run tauri build
```
